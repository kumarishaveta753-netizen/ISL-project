### 1. Welcome & Simple Project Overview

Welcome to ISL Connect! Think of this website like a digital bridge. A user turns on their web camera, performs Indian Sign Language (ISL) hand signs, and the computer translates those signs into text and speech. The website also lets people learn signs through videos and practice them using the camera.



**Important Rule (Scope):** 

Our first version (MVP - Minimum Viable Product) only supports **10 to 20 signs**. We are NOT translating full grammar or full sentences yet.



**Your Job in 2 Sentences:**

1. **As Team Leader:** You organize the team, set deadlines, and make sure everyone works together smoothly.

2. **As Backend Developer:** You build the central server (using Flask) that receives camera data from Sweety (Frontend), asks Madhu's AI model what sign it is, saves user progress in a database, and sends answers back to the browser.

### 2. Tools You Will Use & Why

* **Python (3.10 or higher):** The primary programming language for our backend logic.

* **Postman / Hoppscotch:** Free desktop/web tools used to test your backend endpoints to ensure they work before connecting them to Sweety's website.

#### Step 4: Write Your First Flask Server (`app.py`)

Create `app.py` and write this simple starter code:



```python

from flask import Flask, render_template, jsonify, request

from flask_cors import CORS



app = Flask(__name__)

CORS(app)  # Allows Sweety's frontend to talk to your backend without web blocks



@app.route('/')

def home():

    return render_template('index.html')  # Loads Sweety's main page



@app.route('/health', methods=['GET'])

def health_check():

    return jsonify({"status": "Backend server is running smoothly!"})



if __name__ == '__main__':

    app.run(debug=True, port=5000)

```

Run it in your terminal with `python app.py` and open `http://127.0.0.1:5000` in your browser.



#### Step 5: Build API Routes (How Frontend Talks to Backend)

You need to create specific web addresses (called routes or endpoints) that Sweety's frontend code can call:



1. **Prediction Route (`/predict`):** Receives camera landmarks, sends them to Madhu's AI model, and returns the result.

   ```python

   @app.route('/predict', methods=['POST'])

   def predict_sign():

       data = request.get_json()

       

       if not data or 'landmarks' not in data:

           return jsonify({"error": "No hand data received"}), 400

       

       # Pass landmarks to Madhu's model function

       # Example output format:

       return jsonify({

           "status": "recognized",   # Options: recognized, uncertain, no_hand

           "label": "HELLO",

           "confidence": 0.92

       })

   ```



2. **Confirmation Route (`/confirm-sign`):** Triggered when a prediction is low confidence and the user clicks a choice in Sweety's pop-up menu.

   ```python

   @app.route('/confirm-sign', methods=['POST'])

   def confirm_sign():

       data = request.get_json()

       user_action = data.get('action') # 'confirm', 'correct', or 'repeat'

       selected_sign = data.get('sign')

       

       return jsonify({

           "status": "success",

           "message": f"Sign {selected_sign} updated based on user action: {user_action}"

       })

   ```



#### Step 6: Set Up the Database (SQLite)

Create a file inside `database/db_setup.py`:

```python

import sqlite3



def init_db():

    conn = sqlite3.connect('isl_connect.db')

    cursor = conn.cursor()

    

    # Table to track lessons completed by user

    cursor.execute('''

        CREATE TABLE IF NOT EXISTS progress (

            id INTEGER PRIMARY KEY AUTOINCREMENT,

            lesson_id INTEGER,

            lesson_title TEXT,

            status TEXT

        )

    ''')

    

    conn.commit()

    conn.close()



if __name__ == '__main__':

    init_db()

    print("Database and tables created successfully!")

```
