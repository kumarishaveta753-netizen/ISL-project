#### Step 2: Understand Hand Landmarks (MediaPipe)

MediaPipe detects **21 key points** on a hand (0 is the wrist, 4 is the thumb tip, 8 is the index fingertip, etc.). Each point has $x, y, z$ values.

* 21 points $\times 3$ coordinates $(x,y,z) = 63$ numbers per hand.



Test MediaPipe with this starter script:

```python

import cv2

import mediapipe as mp



mp_hands = mp.solutions.hands

hands = mp_hands.Hands(static_image_mode=True, max_num_hands=1)



# Read an image

image = cv2.imread('sample_hand.jpg')

rgb_image = cv2.cvtColor(image, cv2.COLOR_BGR2RGB)

results = hands.process(rgb_image)



if results.multi_hand_landmarks:

    for hand_landmarks in results.multi_hand_landmarks:

        for lm in hand_landmarks.landmark:

            print(f"X: {lm.x}, Y: {lm.y}, Z: {lm.z}")

else:

    print("No hand found in picture!")

```



#### Step 3: Turn Shaveta's Dataset into Numbers (Preprocessing)

Loop through Shaveta's dataset folders, extract the 63 numbers for every image, and normalize them so hand distance from the camera doesn't confuse the model:



```python

import os

import numpy as np



def extract_normalized_landmarks(hand_landmarks):

    points = []

    wrist_x = hand_landmarks.landmark[0].x

    wrist_y = hand_landmarks.landmark[0].y

    wrist_z = hand_landmarks.landmark[0].z



    for lm in hand_landmarks.landmark:

        # Subtract wrist coordinate so hand position starts at (0,0,0)

        points.extend([lm.x - wrist_x, lm.y - wrist_y, lm.z - wrist_z])

    return points

```



Save all extracted landmarks into an array `X` and sign names into `y`.

#### Step 5: Write the Prediction Function for Pooja

Create a file named `predictor.py` that Pooja can easily call inside Flask:



```python

import joblib

import numpy as np



model = joblib.load('isl_model.pkl')



def predict_hand_sign(landmark_list):

    if not landmark_list or len(landmark_list) == 0:

        return {"status": "no_hand", "label": None, "confidence": 0.0}



    # Convert list to array

    data = np.array(landmark_list).reshape(1, -1)

    

    # Get probabilities

    probabilities = model.predict_proba(data)[0]

    max_idx = np.argmax(probabilities)

    confidence = float(probabilities[max_idx])

    label = model.classes_[max_idx]



    # Confidence Threshold Rule

    if confidence >= 0.70:

        return {"status": "recognized", "label": label, "confidence": round(confidence, 2)}

    else:

        return {"status": "uncertain", "label": label, "confidence": round(confidence, 2)}

```
